# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Mode: fully autonomous. No user questions were asked. Anything not locked in 05-CONTEXT.md is a researcher default, marked **[default]**.
> The Phase 3 tokens (`Colors`, `Spacing`, ThemedText 14/16/20/32 at 400/600) and the Phase 4 "always dark over imagery + 0.6 scrim" rule are reused unchanged.

| Property | Value |
|----------|-------|
| Tool | none (React Native + Expo DOM component; shadcn does not apply) |
| Preset | not applicable |
| Component library | none. RN core + existing `ThemedText` / `ThemedView` / `useTheme` for RN surfaces; plain HTML elements + one CSS-in-TS style object set inside the DOM component |

### Shared RN/CSS tokens [default]

The DOM component must not import `constants/theme.ts` (it imports `react-native` and `global.css`). Add `src/viewer/tokens.ts` with **no imports**, plain literals, consumed by both the DOM component (CSS values) and RN files that sit on the viewer:

```ts
export const VT = {
  bg: '#000000',            // = Colors.dark.background
  surface: '#212225',       // = Colors.dark.backgroundElement
  surfaceSelected: '#2E3135', // = Colors.dark.backgroundSelected
  text: '#FFFFFF',          // = Colors.dark.text
  textSecondary: '#B0B4BA', // = Colors.dark.textSecondary
  accent: '#3CC8B4',        // = Colors.dark.accent
  onAccent: '#000000',      // = Colors.dark.onAccent
  destructive: '#FF6B5E',   // = Colors.dark.destructive
  warning: '#F5A524',       // = Colors.dark.warning
  scrim: 'rgba(0,0,0,0.6)', // Phase 4 HUD scrim
  ghost: 'rgba(255,255,255,0.15)', // joystick base fill
  ghostStroke: 'rgba(255,255,255,0.3)',
  knob: 'rgba(255,255,255,0.6)',
  space: { xs: 4, sm: 8, md: 16, lg: 24, xl: 32, xxl: 64 }, // = Spacing.one..six
  radius: { sm: 8, md: 12, lg: 16, pill: 22 },
  font: { label: 14, body: 16, heading: 20, display: 32 },
  weight: { regular: 400, semibold: 600 },
} as const;
```

One jest assertion checks the color keys equal `Colors.dark` (keeps the copy honest). CSS uses `px` of the same numbers.

## Typography

Same scale as Phase 3: 4 sizes, 2 weights (400, 600). DOM CSS uses identical numbers.

| Role | Size | Weight | Line height | Used for |
|------|------|--------|-------------|----------|
| Label | 14px | 400 / 600 | 20 (1.43) | Hint chips (400), segment labels (600), link row meta line (400), plan panel header (600), field helper/error (400) |
| Body | 16px | 400 / 600 | 24 (1.5) | Viewer title in top bar (600), measure label (600, tabular nums), link URL (400), body text in error/password blocks (400), button labels (600) |
| Heading | 20px | 600 | 28 (1.4) | Loading percent "42%", error/password/404 headings, share sheet section titles |
| Display | 32px | 600 | 40 (1.25) | Share sheet screen title "Share" only |

Rules:
- Percent and distances use `fontVariant: ['tabular-nums']` / CSS `font-variant-numeric: tabular-nums`.
- Top bar title: 1 line, truncate tail. Link URL: 1 line, `ellipsizeMode="middle"` (keeps the slug end visible).
- RN text keeps Dynamic Type with `maxFontSizeMultiplier={1.3}` on viewer chrome (it sits on the 3D view, like the Phase 4 HUD) and 1.6 on the share sheet. DOM text uses `px` and does not scale (WebView ignores Dynamic Type); this is accepted.

## Color

| Role | Value (viewer/web: dark only) | Usage |
|------|-------------------------------|-------|
| Dominant (60%) | `#000000` (`bg`) + the 3D view | Viewer background before the splat renders, web page background, landing page |
| Secondary (30%) | `rgba(0,0,0,0.6)` scrim over the scene; `#212225` (`surface`) on solid backgrounds | Top bar, mode bar, side rail, plan panel, chips, password card, inputs; share sheet cards use `backgroundElement` (light/dark) |
| Selected | `#2E3135` (`surfaceSelected`) | Selected mode segment fill, pressed states |
| Accent (10%) | `#3CC8B4` dark / `#0B7A70` light (share sheet only) | Reserved list below |
| Destructive | `#FF6B5E` dark / `#D92D20` light | Reserved list below |
| Warning | `#F5A524` | Not used in this phase |

Accent reserved for (nothing else):
1. Loading progress bar fill and the indeterminate spinner (DOM: CSS spinner; RN: `ActivityIndicator color`)
2. You-are-here dot (fill) and heading wedge (fill at 0.4 opacity)
3. Measure markers (fill) and measure line
4. "Create link" button fill (share sheet) with `onAccent` label
5. "Open room" button fill (web password gate) with `onAccent` label
6. 2px focus outline on web (`:focus-visible`, offset 2) and the 2px focused-input border (share sheet password field, web password field)
7. Landing page fallback link text "Open the room"

Not accent: selected mode segment (`surfaceSelected` + 600 weight, like Phase 4's segmented control), Reset / Plan buttons (`text` icons), joystick (white ghosts), Share button icon (`text`), lock icon (`textSecondary`).

Destructive reserved for:
1. "Revoke" button text in link rows and the confirm button (`style: 'destructive'`)
2. Inline error text on the share sheet (create, revoke, list failures) and the web password gate (wrong password, rate limited). Viewer load-error and recovery headings use `text`, not destructive

Contrast: `#FFFFFF` on 0.6 scrim over a white scene worst case ≈ 7:1 (scrim alone over pure white gives #666 → 5.7:1 for white text); `#B0B4BA` on `#212225` 7.9:1; `#000` on `#3CC8B4` 10.1:1. Hint chips always sit on the scrim, never directly on the scene.

│ ┌ Plan panel (DOM, when open) ┐        │ top: insets.top + 44 + 8, left 16

| 404 | Heading "This scan isn't available", body "It may have been deleted.", no button (Back is in the top bar) |
| Not ready (deep link) | Heading "This scan isn't ready yet", body "Open it again from your Library when it says Ready." |
| Ready | `WorldViewer` full-bleed + overlays |

### B. Viewer overlays (DOM, shared by app and web)

**B1. Loading overlay (D-05)** — covers the scene on `bg`, centered column:
- Determinate (Content-Length known): stage label (Label 14/400 `textSecondary`) → 8 → percent (Heading 20/600 `text`, tabular) → 8 → bar 200x4 (`surface` track, accent fill, width = percent; no easing beyond `transition: width 150ms linear`).
- Indeterminate: stage label → 8 → 24px accent CSS spinner. No percent, no fake bar.
- Stages: "Downloading room" (bytes), then "Preparing room…" (Spark parse / first frame; indeterminate spinner).
- Percent only increases, rounds down (never shows 100% until bytes are complete).
- Overlay fades out 200 ms once the first frame renders (`onReady`); instant under `prefers-reduced-motion`.
- Mode bar and rail are hidden while loading.

**B2. Mode bar** — `role="radiogroup"` `aria-label="View mode"`, 3 segments `role="radio"` with `aria-checked`: **Orbit · Walk · Measure**. Scrim container; selected segment `surfaceSelected` fill + 600 `text`; unselected 400 `textSecondary` (both 14px). Default mode on open = Orbit.
- No collider (D-10): Walk and Measure segments render at opacity 0.4 with `aria-disabled="true"`; tapping one shows the "no geometry" hint chip for 4 s and does not switch mode.

**B3. Side rail** (right edge, stacked, bottom aligned 8 above the mode bar):
- **Reset** (`aria-label="Reset view"`, glyph: counter-clockwise arrow): returns to start pose (D-07) and Orbit mode; also clears an in-progress measurement. Camera tweens 400 ms ease-out; instant under reduced motion.
- **Plan** (`aria-label="Floor plan"`, `aria-pressed`, glyph: square grid): toggles the plan panel. Not rendered when the world has no floor plan (D-11). Pressed state: `surfaceSelected` fill.

**B4. Hint chip** (one at a time, centered, 8 above the mode bar, scrim pill, Label 14/400 `text`, `role="status"` `aria-live="polite"`). Shows the first time each mode is entered in a session and hides on the first matching input or after 6 s **[default]**:

| Trigger | Touch (`pointer: coarse`) | Desktop (`pointer: fine`) |
|---------|---------------------------|---------------------------|
| Orbit, first open | Drag to orbit · Pinch to zoom | Drag to orbit · Scroll to zoom · Right-drag to pan |
| Walk entered | Left side: move · Right side: look | WASD or arrow keys to move · Drag to look |
| Measure entered / after Clear | Tap a point to start | Click a point to start |
| Measure, 1 point placed | Tap a second point | Click a second point |
| Measure tap missed geometry | Tap on a surface | Click on a surface |
| Disabled Walk/Measure tapped | Walking and measuring need room geometry. This scan doesn't have it. | same |
| Teleport done | You're here now | same |

Measure hints persist (no 6 s timeout) until the next measure step.

**B5. Walk mode (D-09)**
- Left half of the screen (below the top bar, above the mode bar zone = bottom `insets.bottom + 16 + 44 + 8`): floating joystick. On touch-down a base (112, `ghost` fill, 1px `ghostStroke`) appears centered on the finger; the knob (48, `knob`) follows, clamped to 32 px travel; release hides both. Speed scales linearly with knob distance, max 1.4 m/s **[default]**.
- Right half: drag to look (yaw + pitch, pitch clamped ±80°).
- Desktop: WASD / arrow keys move, mouse drag looks (no pointer lock), Shift = 2x speed **[default]**. Keys only act while the canvas or page body has focus (never while typing in an input).
- Collision feedback: movement simply stops at the wall; no flash, no haptic.

**B6. Floor plan panel (D-11)** — DOM, top-left (`top: insets.top + 8`, `left: 16`), scrim, radius 16, padding 8:
- Header row: "Floor plan" (Label 14/600 `text`) left, close button 44x44 (× glyph, `aria-label="Close floor plan"`) right.
- Image: full panel width, aspect from the PNG, radius 8, `surface` behind transparent pixels.
- You-are-here: accent dot 12 + 2px white ring at the camera's xz; heading wedge (60°, radius 24, accent 0.4) pointing along camera yaw. Updates every frame while open.
- Under the image: "Tap to jump there" (Label 14/400 `textSecondary`), 8 top margin.
- Tap on the image → teleport (world xz from pixel, eye height, pushed out of collider) → switch to Walk → panel stays open → "You're here now" chip. If there is no collider, teleport still moves the orbit target/camera to that spot at eye height and stays in Orbit **[default]**.
- Panel `role="dialog"` `aria-label="Floor plan"`; image `role="button"` `aria-label="Floor plan. Tap a spot to move there."`. Esc closes on desktop.
- Plan and Measure can coexist; the panel never blocks the mode bar or rail.

**B7. Measure mode (D-12)**
- Tap 1: raycast collider → accent marker. Tap 2: second marker + accent line + label pill at the line's screen midpoint (scrim, Body 16/600 `text`, tabular): **"≈ 2.41 m (approx.)"**. Always 2 decimals, metres **[default]**. Under 0.10 m shows "≈ 0.07 m (approx.)" as well (no special case).
- Tap 3 starts a new measurement (old one removed).
- A "Clear" chip-button (height 44, scrim, Label 14/600 `text`) appears left of the hint chip position once at least one marker exists; it removes markers and returns to "Tap a point to start".
- Result is announced via the `aria-live` region: "Distance about 2.41 metres, approximate".
- Leaving Measure mode hides markers; returning shows nothing (measurement is not kept) **[default]**.
- In Measure mode, one-finger drag still orbits; a tap = touch with < 8 px movement and < 300 ms.

**B8. WebGL context lost (D-13a)** — inside the DOM component: scene replaced by `bg`, centered 24px accent spinner + "Reconnecting viewer…" (Label 14/400 `text`). If not restored within 5 s, call `onError({ code: 'context_lost' })` and leave the native/web layer to act.

**B9. Viewer load error (inside DOM)** — splat/collider fetch fails or Spark throws: centered block on `bg`: heading "Couldn't load this room" (20/600 `text`), 8, body "Check your connection, then try again." (16/400 `textSecondary`), 24, "Try again" button (44, `surface`, `text` 16/600). Collider or floor-plan failing alone is not fatal: viewer opens in Orbit with Walk/Measure disabled or Plan hidden.

### C. Native crash recovery (app, D-13b)

- On WebView process termination: remount the DOM component with a bumped `key` and the last `onPose`. While remounting, a full-screen RN overlay (`#000`, under the top bar so Back still works): accent `ActivityIndicator` + "Reconnecting viewer…" (Label 14/400 `text`). The normal B1 loading overlay then takes over.
- After the cap (3 crashes in 60 s, `recovery.ts`): overlay shows heading "The viewer stopped working" (20/600), 8, body "This can happen when the phone is low on memory. Reload to try again." (16/400 `textSecondary`), 24, "Reload viewer" button (44, `surface` fill, `text` 16/600). Reload resets the reducer and remounts at the saved pose.
- Web (F) has no native layer: when `onError('context_lost')` fires on web, show the same capped block with a "Reload page" button (`location.reload()`).

### D. Share sheet (`world/[id]/share.tsx`, D-18)

iOS page-sheet modal, system light/dark, `ScrollView`, side padding 16.

```
Share                                   Done     ← title 32/600 left; "Done" 16/600 text, 44 target
24
┌ card (backgroundElement, radius 12, padding 16) ┐
│ Protect with a password         [Switch]        │  Body 16/400; Switch trackColor accent
│ (switch on:) 16                                  │
│ Password label → 8 → secure input (48, r12)      │
│ 8 helper / error line (Label)                    │
│ 16                                               │

└──────────────────────────────────────────────────┘
24
Links (20/600)                                    ← section title
8

     Opened 3 times · Created Nov 24, 2026 (14/400 textSecondary)

```

- Password: `secureTextEntry`, `autoComplete="new-password"`, `textContentType="newPassword"`, min 4 / max 64 characters **[default]**. Create link disabled (opacity 0.4) when the switch is on and the field has < 4 chars. Switch off clears the field.
- Creating: button label "Creating link…" with an `onAccent` `ActivityIndicator` left of it; not pressable. On success: the new link is inserted at the top of the list, the password field clears, the switch turns off, and `Share.share({ url, message: url })` opens immediately (iOS sheet includes Copy). If the user dismisses that sheet, nothing else happens.
- Row: lock icon (`lock.fill` 14, `textSecondary`) before the URL only when `has_password`. Share icon button (`square.and.arrow.up` 20, `text`) → `Share.share`. "Revoke" text button (Label 14/600 `destructive`) → confirmation (E). Rows list only non-revoked links (client filters `revoked_at`), newest first **[default]**.
- Revoke is optimistic: row removed on confirm; on API error it returns in place and the error line shows.
- Open counts refresh when the sheet opens and on pull-to-refresh (`RefreshControl`, accent tint). No polling.
- States: loading list → small accent `ActivityIndicator` under "Links"; empty → empty block; list load failed → inline error (Label, `destructive`) + "Try again" text button (16/600 `text`).
- The share sheet is reachable only from a ready world's viewer (Share hidden otherwise).

### F. Web share page (`src/app/r/[slug].tsx`, D-19)

Always dark, full-bleed `100dvh`, no app tabs, no auth. `expo-router/head`: `<title>{title} · Virtumetry</title>`, `<meta name="robots" content="noindex,nofollow">`.

| State | Renders |
|-------|---------|
| Checking link (`GET /v1/public/shares/:slug`) | `bg` + centered 24px accent spinner |
| 404 (missing / revoked / not ready / deleted) | Centered block, max width 400, 64 from top on mobile, vertically centered on desktop: heading "This link is no longer available" (20/600 `text`), 8, body (16/400 `textSecondary`). No button. Page title "Link unavailable · Virtumetry" |
| Network / 5xx | Heading "Couldn't open this room", body "Check your connection, then try again.", 24, "Try again" (44, `surface`) |
| Needs password | Password gate card (below) |
| Opened | Top bar (44, scrim): title (16/600 `text`, left 16, 1 line). No back, no share. Then `WorldViewer` full-bleed with `insets={{ top: 44, bottom: 0 }}` |

Password gate card: centered, width `min(360px, 100vw - 32px)`, `surface` fill, radius 16, padding 24:
- Heading "This room is password protected" (20/600) → 8 → body "Enter the password the owner gave you." (16/400 `textSecondary`) → 24 → label "Password" (Label 14/400) → 8 → input (`type="password"`, `autocomplete="current-password"`, autofocus, height 48, radius 12, `surfaceSelected` fill, 2px accent border on focus) → 8 → error line (Label `destructive`, only on error) → 16 → "Open room" (52, accent, `onAccent` 16/600, full width). Enter submits.
- Submitting: label "Opening…", disabled. Wrong password clears the field and refocuses it.
- Desktop and mobile use the same card; nothing else on the page.

Presigned URLs expire after 15 min (D-17): the viewer has the bytes already. If a later fetch (e.g. after context loss) gets 403, the page re-calls `open` (password kept in memory for the tab) and retries once, then shows B9 **[default]**.

### G. Backend landing `GET /s/:slug` (D-20)

Minimal server HTML, inline `<style>`, no JS framework, no external assets:
- `<html lang="en">`, `<meta name="viewport" content="width=device-width,initial-scale=1">`, `<meta name="robots" content="noindex,nofollow">`, `<meta name="color-scheme" content="dark">`; header `X-Robots-Tag: noindex, nofollow`.
- OG: `og:type=website`, `og:title={title}` (fallback "Untitled scan"), `og:description`, `og:url` (the `/s/:slug` URL), `og:image` (presigned thumbnail) + `twitter:card=summary_large_image`. All values HTML-escaped.
- **Password-protected links omit `og:image`** and use `twitter:card=summary`, so a preview never leaks the room's interior **[default]**.
- No thumbnail → omit `og:image`, `twitter:card=summary`.
- Body: `#000` background, `system-ui` font, centered column: "Opening {title}…" (16px 600 `#FFFFFF`), 8, link "Open the room" (16px 400 `#3CC8B4`, underlined) to `<WEB_SHARE_ORIGIN>/r/<slug>`. `<meta http-equiv="refresh" content="0;url=...">` + `location.replace(...)`.
- 404 page: same shell, heading "This link is no longer available" (20px 600), body "The owner may have turned it off. Ask them for a new link." (16px 400 `#B0B4BA`). Still noindex; no OG image.

## Accessibility Contract

| Element | Role | Label / state |
|---------|------|---------------|
| Back (RN) | button | "Back" |
| Share (RN) | button | "Share this room" |

| Mode bar | radiogroup / radio | "View mode"; `aria-checked`; disabled segments `aria-disabled="true"` |
| Reset | button | "Reset view" |
| Plan toggle | button | "Floor plan", `aria-pressed` |

| Row share | button | "Share link" |

| Recovery overlay | — | RN: `accessibilityLiveRegion="polite"` + `announceForAccessibility` on cap |

Rules: every control ≥ 44x44 on touch. All DOM buttons are real `<button>` elements with `:focus-visible` accent outline. Color is never the only signal (selected segment also changes weight; disabled also has `aria-disabled` + hint text; lock is an icon + the label). `prefers-reduced-motion`: Reset tween and overlay fades become instant.
