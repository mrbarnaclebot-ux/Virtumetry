# Phase 06.1 Plan 02: Unified Dark Theme Summary

The app is now dark-only on design tokens. `Colors` is one flat token-derived object, `useTheme()` returns it, and `ThemedText` renders the 10 type roles with the legacy names aliased, a `tone` prop and each role's `maxFontSizeMultiplier`. Both layouts use a custom dark navigation theme with a light status bar. Fonts load once at the root: the authed splash waits for fonts (loaded, errored or 2.5 s timeout) and the session read, and the public share page never waits.
