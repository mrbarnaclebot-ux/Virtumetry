## Sampling Rate

- **After every task commit:** quick command for the touched test file(s) + `npx tsc --noEmit`
- **After every plan wave:** full suite command
- **Before `/gsd:verify-work`:** full suite green (≥341 existing + new), both GitHub Actions workflows green
- **Max feedback latency:** 180 seconds
