## Pattern Assignments

### `src/design/tokens.ts`, `glyphs.ts` (config)

**Analog:** `src/viewer/tokens.ts` L1-20. Zero imports with a header comment stating why, plain `as const` object:

```ts
/** Viewer tokens (UI-SPEC). No imports: the DOM component must not pull constants/theme (react-native + global.css). */
export const VT = { bg: '#000000', ... space: { xs: 4, ... }, radius: {...}, font: {...} } as const;
```
Then `src/viewer/tokens.ts` becomes `export { tokens as VT } from '@/design/tokens';`. NOTE: world-viewer.tsx uses the OLD flat keys (`VT.surface`, `VT.surfaceSelected`, `VT.textSecondary`, `VT.accent`, `VT.destructive`, `VT.space.md`, `VT.font.label`, `VT.radius.pill`, `VT.weight`). Every use (about 25 sites, grep `VT\.` in `world-viewer.tsx` and `app/world/[id]/index.tsx`) must be migrated to nested `VT.color.*`/`VT.space.*`. Spacing scale also changes (old `md` = 16, new `md` = 12, `lg` = 16).

### `src/design/first-run.ts` (store, SecureStore sync)

**Analog:** `src/capture/prep-flags.ts` L1-25 (copy verbatim shape: sync `SecureStore.getItem/setItem`, try/catch for web, `'1'` flags):

```ts
import * as SecureStore from 'expo-secure-store';
const read = (k: string) => { try { return SecureStore.getItem(k) === '1'; } catch { return false; } };
const write = (k: string, v: boolean) => { try { SecureStore.setItem(k, v ? '1' : '0'); } catch {} };
```
Add `useSyncExternalStore` listeners on top. Web: `getOnboarded()` must return true (note prep-flags reads false on web, so first-run must special-case `Platform.OS === 'web'`). Test seeding: jest.setup's in-memory SecureStore implements sync `getItem`/`setItem` and `__store`/`__reset()`; tests call `secureStore.__reset()` in `beforeEach` (see settings.test L18-30). Expose a `__resetFirstRunForTest()` (pattern: `__setLocalScansForTest` in `capture/store.ts`, `__resetBudgetBannerForTest` exported from `(tabs)/index`).

## Shared Patterns

New code uses `space/radius` from tokens instead of `Spacing`.

### Import conventions
`@/` alias for everything in `src`; order: external, blank line, `@/` modules; `import type` for types.

### Module test hooks
Exported `__xForTest` functions for module state (`__setLocalScansForTest`, `__resetBudgetBannerForTest`).

### Network/query mocking
`globalThis.fetch = jest.fn()` with `ok(body)` helper returning `{ok:true,status:200,json}` (`library.test.tsx` L69-76); `QueryClient` with `retry:false`.
