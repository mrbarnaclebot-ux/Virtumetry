# Phase 6.1 Human UAT: UI/UX makeover

Everything here runs in Expo Go against the dev backend with the mock provider, so it costs $0. This phase made no backend change and no native build.

## Setup

1. Start the app as in `virtumetry/README.md`, "Test on your iPhone" (Phase 3 steps 1, 2, 5 and 6). Use `<your-email>`, and never commit it. If the Expo tunnel is already running, just reload the project in Expo Go (shake the phone, then tap Reload).
2. To see onboarding again on a phone that already finished it, go to Settings > Replay intro. To see it as a brand-new user, delete Expo Go's data by reinstalling Expo Go.
3. The web share page is on the dev alias, `https://virtumetry--dev.expo.app`, and was redeployed this phase. Create share links in the app (viewer > Share > Create link). Share fixture or demo rooms only.
4. To test Reduce Motion, turn on iOS Settings > Accessibility > Motion > Reduce Motion. For Dynamic Type, use iOS Settings > Display & Brightness > Text Size (the largest size).

Partial in Expo Go:
- The app icon, splash, home-screen name ("Virtumetry") and native tab icons ship with the next dev-client build (Phase 7). Expo Go shows its own icon, and you can see the brand mark on the sign-in screen, onboarding and the empty Library.
- On Android, fonts inside the native WebView viewer fall back to system fonts until Phase 7.
