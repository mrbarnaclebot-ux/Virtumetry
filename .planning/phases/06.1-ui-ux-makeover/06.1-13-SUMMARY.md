# Phase 06.1 Plan 13: World screen and share sheet Summary

The world screen now has a scrim top bar, an "Opening room" indeterminate loader, ErrorState messages (the not-ready state gains "Back to Library"), and coach/haptic wiring into the DOM viewer. The share sheet now has a SheetHeader, a create group, an offline banner, skeleton, error and empty states, and toast outcomes. The revoke confirm Alert is kept.

## What changed

- `world/[id]/index.tsx`:
  - Top bar: ghost `Button` Back with the chevron icon, a `heading` title capped at 1.3, and an `IconButton` "Share this room" that shows only when the room is ready.
  - `ProgressBar` indeterminate bars replace every ActivityIndicator.
  - `ErrorState` handles not found, error ("Try again"), not ready ("Back to Library" calls `router.back()`) and capped ("Reload viewer").
  - `coachSeen` is read once from SecureStore. `onCoachSeen` writes only `walk` and `measure` (T-06.1-33). `onHaptic` maps selection, light and success; unknown kinds do nothing (T-06.1-34).
  - Recovery, remount and URL-refresh logic are unchanged.
- `world/_layout.tsx`: the `[id]/index` route now uses `animation: 'fade'`. `gestureEnabled: false` is kept.
- `share.tsx`:
  - "Link created" toast shows before the system share. Revoke success shows "Link turned off".
  - A revoke failure is now a toast only (same string). There is no inline line any more.
  - When `isInternetReachable === false`: the offline Banner shows and Create link is disabled, with the banner sentence as its hint.
  - The password switch calls `haptic.selection()`. TextField uses `inGroup`. The helper and error strings are unchanged.
- Tests:
  - world-screen: the loader and progress bar, Back to Library, the coachSeen fresh and seeded cases, the onCoachSeen allow-list, and the onHaptic mapping.
  - share-sheet: rendered inside ToastProvider, with toasts, offline, switch haptic, loading skeleton and header checks.

## Deviations from Plan

None in scope. Revoke uses a local Pressable rather than `Button` so it keeps its accessible name (see decisions).
