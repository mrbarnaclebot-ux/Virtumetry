# Phase 06.1 Plan 04: Viewer Tokens, Chrome, Coach Marks and Haptics Summary

The 'use dom' viewer now reads only the single token module (`VT === tokens`). Its chrome is rebuilt to UI-SPEC §7.10 with glyph SVGs, the font.css stacks and no colour literals. It shows the Walk and Measure coach marks once each: the app persists them through the `coachSeen` / `onCoachSeen` props, and the web page through localStorage wrapped in try/catch. Mode changes, measure points and floor-plan teleports fire `onHaptic`.
