## Deviations from Plan

- **TDD ordering:** tests and implementation for Tasks 2 and 3 went into one `feat` commit per task, with no separate RED `test(...)` commit. All behaviours in the plan are covered by the new tests.
- **RNTL 14 API:** `renderHook`, `act` and `unmount` are async in RNTL 14, so the hook tests await them. Test-only change.
- **Lint:** used `jest.requireMock('expo-secure-store')` (the existing auth-client.test idiom) instead of `require` to keep lint warning-free.
- **Haptics hardening:** `run()` also wraps synchronous throws in try/catch, so "never throws" holds even when a native call throws before it returns a promise. This is covered by a test.
