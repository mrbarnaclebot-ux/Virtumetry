## Phase Goal

**As a** the owner, **I want to** run a fixture scan in Expo Go from prep through review, checks, quote, approval and a resumable upload to a "Ready" room in my library, **so that** I can trust the whole capture loop at zero cost before real ARKit capture and paid processing.

<objective>
Vertical slice 1 (server gate): a bad capture (too few frames, tracking gaps, blur, too little coverage, pose jump, walking backwards, broken intrinsics) is refused by the backend validator before any credit is spent, using thresholds that can be tuned from an env var without a build.

Purpose: PROC-01 server half + CAP-05 remote tuning source. Everything later (`:complete`, `/v1/capture/config`, the app's mirrored rules) builds on these exact rules and constants.
Output: `capture-config.ts`, rules-driven `validateSession`, shared `validateStored`, pack job threading, tests.
</objective>
