## Phase Goal

**As a** the owner, **I want to** run a fixture scan in Expo Go from prep through review, checks, quote, approval and a resumable upload to a "Ready" room in my library, **so that** I can trust the whole capture loop at zero cost before real ARKit capture and paid processing.

<objective>
Vertical slice 8 (close the loop in the UI): after Stop the owner reviews the scan, sees whether it passes the device checks, gets a quote, explicitly approves it, watches the upload, and sees either "Processing started" or "Didn't pass checks · Not charged" — with the Library reflecting every local state until the server row takes over and reaches Ready.

Purpose: CAP-09 review, PROC-01 device block + server reason display, PROC-02 explicit approval, PROC-03 upload progress UI.
Output: `src/app/capture/[id].tsx`, Library row updates, RNTL tests.
</objective>
