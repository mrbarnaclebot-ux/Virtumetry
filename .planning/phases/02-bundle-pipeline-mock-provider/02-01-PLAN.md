## Phase Goal

ROADMAP Phase 2 goal (backend-only MVP phase; slice = one end-to-end capability through bundle → provider → DB → test): The on-disk session format is fixed. A recorded session can be turned by the backend into a valid Echo-3 capture bundle and run end to end through the mock provider to a ready world with re-hosted outputs, without spending a credit.

<objective>
Fix the session format contract (schema 1) and build the pure bundle building blocks plus the committed fixtures that every later slice consumes: zod manifest, ARKit→OpenCV conversion, EXIF APP1 writer, D-06 validator, ZIP central-directory reader, the ~30-frame TUM-derived fixture session and the mock-output placeholder files.

Purpose: PROC-04 correctness lives here (pose math and EXIF are the parts that silently cost a paid run if wrong). Everything is pure TypeScript so it is unit-testable on Windows.
Output: `backend/src/bundle/{manifest,convert,exif,validate,zipread}.ts`, unit tests, `backend/scripts/make-tiny-session.ts`, `backend/test/fixtures/{tiny-session,mock-outputs}/`.
</objective>
