## Phase Goal

ROADMAP Phase 2 goal (backend-only MVP phase; slice = one end-to-end capability through bundle → provider → DB → test): The on-disk session format is fixed. A recorded session can be turned by the backend into a valid Echo-3 capture bundle and run end to end through the mock provider to a ready world with re-hosted outputs, without spending a credit.

<objective>
Vertical slice "mock-signed webhook → verified, deduplicated nudge → tracker reaches ready", plus the polling fallback when webhooks are dropped (ROADMAP SC3, PROC-06; PROC-10 duplicate_webhooks / webhook_dropped scenarios).

Purpose: Echo-3 runs take 30 min to 2 h; webhooks make "ready" prompt, polling makes it certain. Webhooks must never be a second writer of world state.
Output: `src/routes/webhooks.ts`, registration in `routes/index.ts`, unit + pg tests.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-28 | Spoofing | forged webhook | mitigate | HMAC-SHA256 over raw bytes via verifyWebhookSignature (secretEquals, constant time) before any DB access; unset secret → 401 |
| T-02-29 | Tampering / Replay | replayed delivery (no signed timestamp) | mitigate | delivery_id primary key + ON CONFLICT DO NOTHING; handler is nudge-only, so a replay can at most trigger a free status poll |
| T-02-30 | Denial of Service | webhook flood / large bodies | mitigate | per-IP route rate limit RATE_LIMIT_WEBHOOK_MAX, 256 KiB bodyLimit, O(1) handler |
| T-02-31 | Tampering | second writer of world state | mitigate | route never updates worlds (acceptance grep); only track writes status |
| T-02-32 | Tampering | JSON re-serialisation breaking signature / parser confusion | mitigate | scoped raw-buffer parser after removeAllContentTypeParsers; body never parsed |
| T-02-33 | Information Disclosure | secret in responses/logs | mitigate | responses use fixed error codes; logs carry delivery id + event only; unit test asserts body lacks the secret |
</threat_model>
