## Phase Goal

ROADMAP Phase 2 goal (backend-only MVP phase; slice = one end-to-end capability through bundle → provider → DB → test): The on-disk session format is fixed. A recorded session can be turned by the backend into a valid Echo-3 capture bundle and run end to end through the mock provider to a ready world with re-hosted outputs, without spending a credit.

<objective>
The core vertical slice: a scan seeded from the fixture goes pack → submit → track → import → ready through the worker against the mock provider, with outputs re-hosted in our storage (ROADMAP SC2, PROC-07) and the submit state machine (persist-before-spend, budget refusal, error matrix per D-17) built provider-agnostically so Phase 6 only adds `echo3.ts`.

Purpose: This is the loop the whole phase exists for. MVP ordering: Task 1 writes the failing end-to-end test, Tasks 2-3 make it pass.
Output: `src/pipeline.ts` (pack/submit/track handlers), worker wiring, reusable test harness, pipeline integration test.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → provider submit | the only credit-spending call |
| provider artifacts → our storage | provider-supplied bytes copied into our bucket |
| worker logs | operational logs may be shipped off-box |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-22 | Tampering (self-inflicted double charge) | submit retry | mitigate | submission_key set-if-null once; submit_body persisted then read back and sent verbatim; RetryLaterError reuses key+body; no code path mints a second key |
| T-02-23 | Elevation of Privilege (spend) | unapproved / over-quote / over-budget submit | mitigate | NOT_APPROVED, QUOTE_ABOVE_APPROVAL, BUDGET_EXCEEDED checks before provider.submit; tests assert calls.submit === 0 |
| T-02-24 | Repudiation | ledger under-count | mitigate | release only on 400/402/403, FAILED, CANCELLED, 429/503 exhaustion; reservation kept on 409/5xx/timeout (Pitfall 7) |
| T-02-25 | Information Disclosure | presigned URL in logs / failure_message | mitigate | logs carry ids/keys only; failure_message built from codes; acceptance grep forbids logging zip_url/submitBody |
| T-02-26 | Denial of Service | lease held across long polls / imports | mitigate | snoozeJob between polls; heartbeat between artifacts; streams not buffers |
| T-02-27 | Tampering | artifact name → storage key | mitigate | keys built by worldAssetKey from the provider's fixed artifact list; mock allowlist; live client (Phase 6) must map kinds to fixed names |
</threat_model>
